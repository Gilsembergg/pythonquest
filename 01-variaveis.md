# 🐍 01 — Variáveis

Variáveis são usadas para armazenar informações que podem ser utilizadas durante a execução de um programa.

Em Python, não é necessário declarar o tipo da variável:

```python
nome = "João"
idade = 18
altura = 1.75
```

Podemos visualizar os valores usando `print()`:

```python
print(nome)
print(idade)
```

## 🧩 Desafio

Qual será o resultado?

```python
x = 10
x = x + 5

print(x)
```

* [ ] 5
* [ ] 10
* [ ] 15
* [ ] Erro

<details>
<summary>💡 Ver resposta</summary>

**15.**

A variável começa com o valor `10`. Depois, `5` é adicionado ao valor existente.

</details>
