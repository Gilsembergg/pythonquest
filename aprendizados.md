# Aprendizados

Durante o desenvolvimento do projeto Python Quest, pude praticar conceitos relacionados à programação em Python e também ao uso do Git e GitHub.

## Python

No projeto, revisei e pratiquei conceitos fundamentais de Python, como:

* Variáveis e tipos de dados;
* Estruturas condicionais;
* Laços de repetição;
* Organização e execução de programas em Python;
* Resolução de desafios utilizando lógica de programação.

## Git

Durante o desenvolvimento do projeto, também aprendi a utilizar comandos e conceitos importantes do Git, como:

* Criar e utilizar branches;
* Fazer commits para registrar alterações;
* Consultar o histórico utilizando `git log`;
* Alternar entre branches utilizando `git switch`;
* Trabalhar com diferentes versões do projeto;
* Resolver conflitos entre branches;
* Fazer push das alterações para o GitHub.

## GitHub

No GitHub, aprendi a trabalhar com:

* Repositórios;
* Branches;
* Pull Requests;
* Integração das alterações de um branch para outro;
* Registro e apresentação do histórico de desenvolvimento.

## Principal aprendizado

O principal aprendizado foi perceber que o Git não serve apenas para guardar versões dos arquivos. Ele permite organizar o desenvolvimento, testar alterações separadamente através de branches e integrar mudanças de maneira controlada utilizando Pull Requests.
